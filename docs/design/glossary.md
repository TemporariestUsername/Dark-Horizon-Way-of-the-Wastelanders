# Glossary

| Term | Meaning |
|---|---|
| **Ability** | A class power with an AW move name and a numeric effect, unlocked at a set level in a set track. See [06](06-playbooks.md). |
| **Affection** | A 0–100 bond with an officer or named NPC. Leads to off‑screen intimacy and, at 90, a committed partner. |
| **Ambition** | A faction's plan: four ordered goals with concrete conditions, which the AI works toward. Shown as rumored plans, never as a clock. |
| **Arms / Training** | A gang's equipment and drill, each 0–100. With troops, they set gang‑war strength (Inindo's *Arms / Training*). |
| **Attributes** | Cool, Hard, Hot, Sharp and Weird, each 1–100. AW's names on UWNH/Inindo scales. |
| **Backing** | A sub‑faction's support for a faction. It adds Lean drift wherever the sub‑faction has chapters. |
| **Barter / 1‑barter** | The unit of account. About a month's modest living. |
| **Break** | A blocked road: an overpass down, a bridge out, a pileup. UWNH's reefs. |
| **Burning Water** | Parcher's faction: the Texas City refineries. Wins holds through fuel. The Choir's nearest neighbour. |
| **Cerro** | Otilia's faction: walled Monterrey. Wins holds through walls. |
| **Chapter** | A sub‑faction's foothold in a hold. It gives Presence. Secret societies' chapters are hidden. |
| **Charts** | Records of driven roads (breaks, crossings, holds, tolls). Sold to the News, hardholders and Rothschild. |
| **Check** | Anything outside battle that can fail. Its chance is shown before you commit. See [04](04-characters.md#checks). |
| **Choir, the** | The Nobunaga faction: Last's brainers in Harrowgate, with Tum Tum's flesh trade. It doesn't play Lean; it Silences holds. See [17](17-factions.md). |
| **Class** | A playbook as a class: starting attributes, growth, abilities, a signature asset, and an arc. |
| **Convoy** | Up to 6 rigs travelling together. UWNH's fleet. |
| **Crossing** | A bridge, dam, ferry or tunnel over a living river. UWNH's straits. Usually tolled. |
| **Discipline** | A set of 3 techniques taught at a maelstrom site, costing Grit. Inindo's magic school. See [04](04-characters.md#disciplines-inindos-magic-schools). |
| **Durability** | A rig's HP in road war. |
| **Easing, the** | The maelstrom quieting, a little over a year before the game starts. The first chance in a generation to travel. |
| **Exchange, the** | Rothschild's faction: Tampa. Wins holds through debt and salvage. |
| **Faction** | One of six hardholder powers competing for Lean (the Lighthouse, Sweetwell, Highwater, the Exchange, Burning Water, Cerro), or the Choir. See [17](17-factions.md). |
| **Family, the** | A secret society (sub‑faction) under the Deep Lines, led by Mother Krin. Hidden chapters. Hum‑touched. |
| **First contact** | Your first arrival at a hold nobody from outside has reached since the Howling. |
| **Frame** | A vehicle's base type (bike, compact, hauler…). UWNH's hull. |
| **Gig** | A job. Posted at month start on notice walls, at faction seats and at sub‑faction halls. |
| **Golden Age** | The world before. Never explained. |
| **Grip** | A faction leader's strength: Weak / Holding / Strong / Iron. Sets actions per month. |
| **Grit** | The energy disciplines and some abilities cost. Inindo's MP. |
| **Health (HP)** | Hit points. At 0 a character is down. |
| **Highwater** | Abondo's faction: the Great Lakes. Wins holds through freight and the winter ice roads. |
| **Hold** | A settlement. UWNH's port, Inindo's castle town. There are 130 (see the [Gazetteer](16-gazetteer.md)). |
| **Howl** | A local flare of the old maelstrom on a stretch of road. UWNH's calm, made psychic. |
| **Howling, the** | The generation when the maelstrom made every open road deadly. |
| **Hum exposure** | A hidden 0–100 value for each character. At 50 the Choir can reach you directly; at 100 the "*join them*" endings open. |
| **Hum level** | A hold's 0–100 measure of the Choir's hold on it: Touched at 30, Marked at 60, Silenced at 100. |
| **Hum, the** | Last's broadcast into the maelstrom, and the sound of the Choir spreading. See **Hum level**. |
| **In, the** | The maelstrom as a traversable map layer. |
| **Interstate** | A great road, called by its number ("the Ten"). UWNH's ocean. |
| **Jingle** | Small change. 10 jingle = 1‑barter. |
| **Keepers, the** | A cult (sub‑faction) that kept the bridge lamps lit through the Howling. Backs the Lighthouse. |
| **League, the** | The anti‑Choir coalition the player can broker once the Choir is Spreading. It collapses if its **tension** reaches 100. |
| **Lean** | A hold's loyalty shares, totalling 100. 50 or more means it leans to that faction. |
| **Levels** | Road, Trade and Fight, each 1–20. UWNH's three experience tracks. |
| **Lifestyle** | Monthly upkeep, 1–2 barter. |
| **Lighthouse, the** | Clarion's faction: the free Memphis bridge. Wins holds through passage. |
| **Loud, the** | The Out: everywhere past the map's edges where the maelstrom never eased. |
| **Loyalty** | An officer's 0–100 bond to you. Raised by wages and wants, lowered by neglect. Below 30 they may leave. |
| **Maelstrom, the world's psychic** | AW's ever‑present psychic storm. |
| **Mark** | A warlord's safe‑passage token. UWNH's Letter of Marque and tax permit. |
| **Marked** | A hold at Hum 60 or more. The Choir's circle is on its doors, and its Lean drains to no one. |
| **Month Report** | The "*meanwhile…*" broadsheet at the end of each month. |
| **Morale** | Your hands' 0–100 spirit. Below 30 they desert; below 15, mutiny. |
| **Octant** | A direction on the world map: N, S, E, W, Up, Down, In, Out. |
| **Officer** | A named crew member in a convoy role (First Mate, Navigator, Quartermaster, Mechanic, Medic, Gunner, Weird). UWNH's mates. |
| **Opened, the** | People whose brains the Choir has opened. The Choir's soldiers. They never break. |
| **Perk** | A sub‑faction's signature benefit, open at Standing +75. |
| **Presence** | A sub‑faction's strength in a hold (1–3). It isn't Lean. |
| **Quiet, the** | The region where the maelstrom eased: the playable map. |
| **Reach** | How many holds the Choir has Silenced. Its tiers (Whispers, Spreading, Marching, Drowning) set how harsh the world is. |
| **Renown** | Map‑wide fame in three kinds (Explorer, Trader, Raider), each 0–1,000. UWNH's fame. |
| **Rep** | Reputation in a hold, −3 to +5. Shifts prices ±5% a step and gates gigs and recruiting. |
| **Rig** | A vehicle in your convoy. |
| **Ring** | Distance band on the world map: Centre (the Crossing), Closer, Farther, Notional. Sets event danger. |
| **Rough, the** | Off‑road. UWNH's land. Off‑road frames only. |
| **Seat** | A faction's home hold. Can't be invested in. |
| **Sight** | A discovery. UWNH's discoveries. |
| **Silenced** | A hold at Hum 100: the Choir's. It's off the influence board and can only be liberated, never bought back. |
| **Skill** | Driving, Navigation, Wrenching, Trading, Gunnery, Brawling, Medicine, Scouting or Lore, ranked 1–3. Trained at sub‑faction halls. |
| **Standing** | Your relationship with a sub‑faction, from −100 to +100. Gigs at +25, recruits and services at +50, the perk at +75; hostile at −50. |
| **Sub‑faction** | A cult, road gang, guild or secret society that cuts across faction lines. See [18](18-sub-factions.md). |
| **Surplus / Want** | A hold's 0–3 levels per resource. They drive prices and afflictions. |
| **Sweetwell** | Grome's faction. Wins holds through thirst. |
| **Teeth, the** | The biggest road gang (sub‑faction), Dremmer's. They raid the west. |
| **Threat** | A named gang, beast, cult or affliction on the map, tagged with an AW threat kind. It drives events where it is. See [05](05-events.md). |
| **Touched** | A hold at Hum 30 or more: bad dreams, and people leaving for Harrowgate. |
| **Turning** | The Choir corrupting a Hum‑touched sub‑faction: progress from 0 to 100. A turned chapter lets a hold be Silenced from inside. |
| **Voices** | The Choir's strength: people taken in. More voices make the Hum seep faster. |
| **Wanderer AI** | Named NPCs taking Inindo's monthly verbs (Move, Attack, Flee, Seek work, Work, Train, Wait, Meet). |
| **World turn** | The end‑of‑month simulation step. |
