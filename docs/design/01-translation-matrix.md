# 01 · Translation Matrix

Every system found in the teardowns ([UWNH](../research/uncharted-waters-new-horizons.md), [Inindo](../research/inindo-way-of-the-ninja.md)) and every AW rule in [the source notes](../research/apocalypse-world-source-notes.md) is mapped here: kept, translated or deliberately cut.

| Storm / calm / rats / scurvy | **Dust storm / the Calm / scavvers in the stores / rot** | [08](08-travel-and-vehicles.md) |
| Lime juice, rat poison, balm | Antiseptic, traps, a hocus' blessing (augury) | [13](13-content-tables.md) |
